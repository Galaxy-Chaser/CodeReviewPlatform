# 协作同步成本与复测（v1.24）

协作页仍每 5 秒检查变化，隐藏页面暂停，离开页面停止，未保存的搜索和编辑内容保持不变。v1.24 复用同一份已提交元数据的变化标记，减少空闲轮询反复筛选、排序和生成摘要的工作；不缓存需求、任务、知识正文、历史或凭据。

## 复用的边界

- 标记按记录类别、项目授权范围和知识发布过滤分别保存。同一范围的项目顺序和重复编号不改变结果；空范围与全部项目仍不同。
- 每份当前元数据最多保存 64 个范围标记。只缓存最多 31 个、每个最多 36 字的项目编号；更大的调用范围直接计算。
- 可见 agent 租约到期时立即重算，不延长领取。系统时间回退也重算；人工领取继续遵循原有规则。
- 成功写入发布新的不可变元数据，旧标记不再参与新提交的判断。旧元数据不再被引用后可以回收；索引与标记均不持有正文。
- 每次请求仍先检查 agent 凭据和项目授权；撤销、版本冲突、人工审核和质量门禁不受复用影响。

复用标记不会减少首次读取工作区或列表/详情的成本，也不会提高原有 3,000 条记录、8 MiB 工作区上限。

## 如何实际测量

安装平台依赖后，在平台目录运行：

```powershell
npm run measure:collaboration
# 或
node --expose-gc scripts/measure-collaboration.js
```

脚本只创建临时样本，启动独立的真实平台服务，清空服务的 Sonar/GitHub 凭据，测量完成关闭进程并清理样本。正式 `data` 和项目源码不参与测量。最终报告保存到 `outputs/collaboration-measurement/report-编号.json`，包含代码摘要和实际测试条件，不包含 agent 凭据、记录正文或用户项目路径。测量报告不进入迁移源码包。

固定两种有效样本：每类 10 条，共 30 条；每类 1,000 条，共 3,000 条。大样本接近 8 MiB 上限，含真实长度的正文、历史、绑定需求、领取状态、项目知识和通用知识，经过正常工作区校验。

每种样本分别测量全部任务、最多 30 项目任务、单项目需求和已发布知识的核心标记成本。每种范围先读取一次，再执行 5 批，每批 200 次：`medianBatchMeanMsPerCall` 是五个“每批平均每次耗时”的中位数；`p95BatchMeanMsPerCall` 也是批均值分位数，不能当作 1,000 个请求的延迟分位数；`totalWallMs` 是五批实际耗时的总和，原始五批耗时保留在 `elapsedBatchesMs` 供核对。CPU 为实际进程计数，较短测量可能因系统粒度显示为零。堆变化是 GC 后观察值，不是总分配量。

真实 HTTP 部分授权 20 个 agent，先读取标记，记录服务内存，空闲 5 秒再次读取内存，再发出 10 轮、每轮 20 个并发请求。确认所有回复与完整列表的标记一致、列表每页最多 25 条，撤销后凭据不能继续同步。每个样本的服务阶段限 60 秒，启动和单次请求最多 15 秒。HTTP 的中位数与 p95 来自 200 次单独请求；总等待耗时可重叠，整个批次耗时另列 `wallMs`。

这是加速请求样本，覆盖独立服务，不包含浏览器、Java/Maven/Sonar 的内存和工作。RSS/堆来自正常服务的实测快照，不能据此保证所有场景的峰值或通用内存降幅。测试主进程的 `--expose-gc` 用于观察核心堆保留，独立平台服务仍使用正常 GC。

## 测量与验证记录

最终对照数据与完整自动验收记录见 [协作迭代计划](AGENT-SYNC-PLAN.md)。基线来自已提交 v1.23，使用与 v1.24 相同的测量脚本、运行时、固定样本规模和请求次数，顺序执行避免相互争抢资源。

2026-10-07 本机对照：3,000 条有效记录约 7.7 MiB。以下为预热后的核心标记计算每次耗时，单位毫秒，按上述五批均值口径计算；不包含首次工作区读取、列表、网络或浏览器渲染。

| 大样本范围 | v1.23 | v1.24 |
| --- | ---: | ---: |
| 全部任务 | 0.3033 | 0.0003 |
| 30 项目任务 | 0.3415 | 0.0047 |
| 单项目需求 | 0.0413 | 0.0006 |
| 授权项目及通用的已发布知识 | 0.1106 | 0.0047 |

独立服务的 20-agent 加速请求中，大样本 200 次 HTTP 回复中位数从 7.62 ms 到 2.82 ms，p95 从 12.83 ms 到 6.75 ms。小样本中位数约 3.24 ms 和 3.47 ms，未显示相同的整体加速。大样本空闲 RSS 约 73.9 MiB 和 73.4 MiB，堆均约 7.6 MiB；这些快照不证明通用内存降幅。64 个标记填满后，受控 GC 检查确认不再被引用的旧索引可以回收。
